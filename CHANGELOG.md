# Changelog

## 1.2.0 — 2026-10-01
- Added bidirectional Dijkstra.
- Added optional diagonal movement with corner-cut prevention.
- Added Manhattan/Chebyshev heuristic explanation.
- Added expanded counts and illustrative browser timings for four algorithms.
- Added deterministic seeded random maps.
- Expanded cross-algorithm regression tests.

## 1.1.0 — 2026-09-30
- Added BFS as a fewest-step baseline and exposed cost-versus-steps trade-offs.

## 1.0.0 — 2026-09-30
Initial standalone browser application, local development server, examples, input guards, unit tests, and explicit export controls.
